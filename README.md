# Yoga Studio — SDD MVP

Proyecto de demostración construido a partir de una spec (Spec Driven Development).

## Feature implementado
Gestión principal de bonos, reservas, aforo y lista de espera.

## Ejecutar
Abrir `src/index.html` en un navegador. No requiere instalación.

## Documentos SDD
- `AGENTS.md`: contexto persistente e instrucciones generales.
- `specs/bonos-reservas.md`: definición del feature y criterios de aceptación.
- `skills/brand-design/SKILL.md`: skill de identidad visual.

## Alcance de la demo
La interfaz utiliza datos de demostración en memoria. No incorpora autenticación, base de datos compartida ni envío real de notificaciones. Para producción se requiere backend, persistencia, autorización y operaciones transaccionales.
